## Tasks

1. From the gallery, explain the frame-FIFO failure and distinguish the model
   proposal from the maintainer control without assistance.
2. Open the editable workspace. Reproduce one original failure, then check a
   supported candidate. Explain exactly what the bounded result establishes.
3. Edit the source after a completed review. Identify whether the displayed
   result applies to the new bytes. Export the verified source and evidence.
4. Inspect the NVIDIA partial AXI repair and explain why four passing
   regressions do not qualify it for acceptance.

Record completion, points of confusion, interventions and participant wording.
Time tasks consistently, report actual durations rather than estimated savings,
and separate first-use learning from later task time.
