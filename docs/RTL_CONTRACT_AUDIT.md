# RTL contract and environment audit

This is an agent-conducted source and harness review. It is **not** an independent
designer evaluation, user study or FPGA hardware validation.

## Common boundary

Only the three pinned upstream modules are supported. Candidate license/header,
parameters, ports, configuration-checking initial blocks and compiler directives
must remain unchanged. Simulation and formal scripts are generated by trusted
code, not supplied by the candidate or model. No system tasks, new initial blocks,
hierarchical reference/testbench access, timing delays or unknown literals are
accepted in candidate logic. Workers have filesystem/network namespaces, no
provider environment, bounded resources and fixed commands. Workspace execution
uses one worker slot per host.

The independent simulation oracle reconstructs accepted interface transfers.
It does not read internal pointer names or compare waveforms to a model-provided
expected answer. Directed tests establish the observed scenarios, not exhaustive
behavior. Historical fixed RTL is the bounded-reference oracle and is excluded
from prompts. Known public code might have appeared in training data.

## FIFO reset flush

- Fixed instance: 8-bit payload, four memory words; three write/read clock and
  prefill combinations. The source/receiver obey the testbench handshake tasks.
- Both reset inputs are asserted and held during the directed flush scenario.
  The post-reset observation starts after synchronizer settling, with no new
  input words. A pre-reset word appearing there violates flush semantics.
- Subsequent 0x61/0x92 transfers must preserve order, TLAST and TUSER. Tying output
  valid low cannot satisfy the fresh-traffic obligation.
- Formal bound: 16 symbolic steps. Independent clock levels use `clk2fflogic`.
  The existing OR of the two asynchronous reset inputs is named explicitly for
  Yosys lowering. This is not CDC/metastability analysis or 16 full clock cycles.
- The directed witness is independently simulated; it is not a replay of the SAT
  stimulus. No minimum or globally shortest counterexample claim is made.

## AXI source TKEEP disabled

- Fixed source: 8 bits; output widths 8, 16 and 32; source TKEEP enabled/disabled.
  Output TKEEP is enabled. ID/DEST are 2 bits, USER is 1 bit.
- With S_KEEP_ENABLE=0 the physical zero input mask is semantically ignored:
  every input byte is valid. With source TKEEP enabled, interior masked bytes
  are excluded. Frame metadata is held constant within each generated frame.
- Four five-transfer input frames produce 20 or 16 valid bytes depending on
  source mask mode. Reconstruction uses little-endian byte lanes and output
  TKEEP. Padding bytes of a partial final output word are excluded.
- Input data/sidebands are driven on falling edges and held across backpressure;
  the oracle samples before rising-edge nonblocking register updates. Output
  valid/data/sidebands must remain stable while the receiver is stopped.
- Four 20-step, single-clock bounded comparisons cover the listed profiles.
  Data comparison is qualified by reference valid and each reference TKEEP bit.
  Downsize and arbitrary width/mask combinations are not established.

## Frame FIFO full-pointer failure

- Fixed instance: four memory words, 8-bit data, FRAME_FIFO=1,
  DROP_WHEN_FULL=0, DROP_BAD_FRAME=0; enabled KEEP/LAST/ID/DEST/USER.
- Eight three-byte frames each fit individually. Continuous ready, an initial
  pause, and repeated pauses are separate regressions. A receiver eventually
  resumes; this is not a proof of progress under permanent backpressure.
- The source holds a word until an actual ready/valid transfer. Expected bytes,
  frame boundaries, metadata and no-drop status are checked independently.
- The historical original passes the first two directed patterns but only
  preserves 16 of 24 bytes under repeated pauses. This is not described as a
  generic failure under every stall pattern.
- A 20-step positive-control comparison timed out and remains UNPROVEN in its
  qualification artifacts. Before any model request for this third case, the
  fixed 12-step comparison was calibrated: original counterexample, maintainer
  control pass. The frozen experiment uses 12 steps. It is not unbounded proof.

## Acceptance and unresolved scope

Every directed regression and every required bounded comparison must pass.
Errors, malformed observations, X-valued accepted traffic and timeouts cannot
be promoted to acceptance. Yosys may exit zero after SAT timeout, so explicit
SUCCESS text is required. The first case's reset normalization and the third
case's 12-step bound remain visible in result records.

These observations do not establish placed-and-routed timing, area, power,
physical board behavior, all parameterizations, model superiority, a new
debugging algorithm or novelty of the known upstream defects.

The bounded oracle requires cycle-level agreement with the pinned maintainer
reference, including ready/valid timing and status outputs. This is a conservative
admission rule; a different legal buffering architecture can be rejected even if
it preserves the same stream. Bounded stimuli are not restricted to the three
directed scenarios or to AXI source stability. A reference mismatch therefore
must not be described, by itself, as proof of an invalid AXI design under every
legal environment. Experiment totals are acceptance counts under this rule,
not general semantic-repair accuracy.
