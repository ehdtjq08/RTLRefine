# Superseded development study: oracle scope error

Do not use the v1 normal-control rejection as evidence of a damaged design.
Post-run inspection showed that its frame-length audit generated noncontiguous
TKEEP masks while the corrected research control only counted contiguous
low-order masks. The NVIDIA popcount rewrite was a valid improvement for the
broader public role we had described. Calling that rewrite harmful was incorrect.

The frozen v1 outputs and raw 25 requests remain unchanged for audit, but this
study is superseded for submission by a separately qualified v2 study. V2 narrows
frame-length inputs to the reference's documented behavior, masks invalid payload
outputs, excludes implementation-specific SPI debug data, and independently
checks the frame-length oracle before any v2 inference. Both study results remain
separate. The v1 video contains the superseded interpretation and must not be
used as the final submission video.
