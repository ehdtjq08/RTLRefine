# Title

RTLRefine: Checked RTL Repair with NVIDIA Nemotron on Nebius

# Description

RTLRefine brings RTL source, failing simulations and independently checked
repairs into one browser workspace. NVIDIA Nemotron 3 Ultra proposes design
edits through Nebius Token Factory; the native tools and supplied testbenches
determine whether the exact exported source passes.

This continuous, captioned recording shows an actual fresh NVIDIA request,
a 129-bit multi-file project, the resulting source diff, a downloaded ZIP
reimported for fresh verification, and rejection of an intentionally incomplete
developer patch that passes public checks but fails an audit.

Source: https://github.com/ehdtjq08/RTLRefine
Runnable test build and instructions:
https://github.com/ehdtjq08/RTLRefine/blob/v1.2.1/docs/JUDGE_QUICKSTART.md

The 15.0x figure covers complete-pool screening of the same 118 candidates in
three historical profiles, one paired run per profile on one host. It does not
apply to uploaded projects or measure end-to-end AI repair speed. Uploaded
projects are checked against their supplied benches; this does not establish
unbounded correctness, timing or physical CDC safety.

Built for the Nebius x NVIDIA Global AI Hackathon, Coding and Agentic Engineering
track. The example RTL is authored integration material; historical cases retain
their upstream attribution. English captions are embedded. No music is used.
