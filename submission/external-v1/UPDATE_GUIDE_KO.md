# 외부 RTL 실증을 제출에 반영하기

1. 새 통합 영상 `video/RTLRefine-external-validation-demo.mp4`를 YouTube에
   공개(Public)로 올리고 Devpost Video URL을 새 주소로 갱신합니다.
2. About을 `DEVPOST_ABOUT.md`로 갱신합니다. I를 사용하는 개인 참가 문구이며
   실제 외부 회귀 1건 수리와 다른 개발자 정상 모듈을 구분했습니다.
3. 테스트 빌드 URL은 `PROJECT_FIELDS.md`의 v1.4.1 링크로 갱신합니다.
   `/external-validation`에서 실제 원본·수정본·다른 개발자 모듈을 다시 검사할
   수 있습니다. API 키나 새 추론 요청은 필요하지 않습니다.
4. 외부 사례 스크린샷과 도구 피드백을 갱신하고 최종 제출 상태를 확인합니다.

외부 회귀는 유지보수자가 되돌린 알려진 처리량/버퍼 용량 문제입니다.
새로운 버그 발견이나 모든 AXI 수신기의 규격 위반으로 표현하지 않습니다.
추가 정상 대조군의 leaf 소스는 수정하지 않았고, 어댑터 사용을 명시했습니다.
assertion 횟수는 실행된 검사 횟수이며 프로젝트 수나 무한 상태 증명이 아닙니다.
