# Functional FIFO repair and portable regression exports

This is the v1.4 extension's own development cohort. The earlier property-only
records remain unchanged in `demo/property_repair`. Examples are authored
integration fixtures and healthy controls, not newly discovered historical bugs
or an unseen repair-accuracy benchmark.

Each current checked export includes the public counterexamples, an upfront
contract sequence, immutable self-checking benches and a standalone Python
runner. Its actual isolated execution is an export gate. Synthesis diagnostics
report mapped logic LUT cells, registers and memory primitives separately.
All source, testbench and artifact hashes remain available in each run.
